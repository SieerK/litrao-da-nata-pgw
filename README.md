# 🍺 Litrão da Nata - Cervejaria

## Sobre o projeto

O **Litrão da Nata** é um site institucional desenvolvido como projeto acadêmico para a disciplina de Desenvolvimento Web.

O objetivo do projeto é apresentar uma cervejaria de forma moderna, responsiva e intuitiva, permitindo que os clientes conheçam os produtos, promoções e realizem pedidos através de um formulário de contato e do WhatsApp.



## Funcionalidades

- Landing Page
- Cardápio de produtos
- Seção de promoções
- Sobre a empresa
- Formulário de contato
- Notificação de confirmação do pedido
- Botão para voltar ao topo
- Navegação com rolagem suave (Smooth Scroll)
- Header fixo (Sticky)
- Layout totalmente responsivo



## Tecnologias utilizadas

- HTML
- CSS
- JavaScript



## Responsividade

O projeto foi desenvolvido utilizando o conceito **Mobile First**, com adaptações para:

- Smartphones
- Tablets (a partir de 768px)
- Computadores (a partir de 1024px)



## Recursos implementados

- HTML validado pelo W3C
- CSS organizado em arquivos separados
- Layout utilizando Flexbox e Grid
- Seções responsivas
- Imagens organizadas em pasta própria
- Formulário funcional
- Botão de retorno ao topo
- Interface moderna com efeitos de transparência
